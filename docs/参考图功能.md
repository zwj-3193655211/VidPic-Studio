# 参考图功能调研与实现方案

> 状态：**第 1 层（图生图 img2img）已实现并验证**；第 2/3 层（ControlNet / IP-Adapter）为可选增强，需下载配套组件。

## 结论速览

| 模型 | 图生图 (img2img) | ControlNet | IP-Adapter |
|---|---|---|---|
| sd15 (SD1.5) | ✅ 已实现 | ✅ 可行（1.5 生态） | ✅ 可行（1.5 生态） |
| sdxl_base (SDXL) | ✅ 已实现 | ✅ 可行（XL 生态） | ✅ 可行（XL 生态） |
| moyu_xl (墨幽XL) | ✅ 已实现 | ✅ 可行（XL 生态） | ✅ 可行（XL 生态） |
| realvisxl (RealVisXL) | ✅ 已实现 | ✅ 可行（XL 生态） | ✅ 可行（XL 生态） |

**关键结论**：四个模型本身都原生支持参考图。能否用「姿态 / 深度 / 线稿」参考取决于 ControlNet 组件，能否用「人脸 / 风格」参考取决于 IP-Adapter 组件——都与底模无关，只需注意 **SD1.5 用 1.5 生态、XL 用 XL 生态**，版本错配会直接失效。

## 第 1 层：图生图 img2img（已实现，零下载）

- **原理**：以参考图为起点做加噪-去噪，`strength` 控制保留程度（0.1≈保留原图，1.0≈完全重绘）。
- **实现方式**：`StableDiffusionXLImg2ImgPipeline.from_pipe(主pipeline)` / `StableDiffusionImg2ImgPipeline.from_pipe(...)` —— 与文生图**共享同一份模型权重**，不增加显存、不重复加载。
- **改动文件**：
  - `services/sd_generation_service.py`：`generate_single` / `generate_batch` 增加 `init_image` + `strength` 参数；懒构建并缓存 img2img 包装器（模型重载/卸载时失效）。
  - `services/generation_service.py`：透传参数。
  - `gradio_ui/generation_tab.py`：新增「参考图」上传组件 + 「参考强度」滑块。
- **使用**：生成页上传参考图 → 调「参考强度」→ 生成。留空参考图即纯文生图，完全向后兼容。

## 第 2 层：ControlNet（构图 / 姿态 / 线稿 / 深度参考，需下载 ~2.5GB）

用途：参考图的**结构信息**（人物姿态、建筑线稿、深度图）严格约束生成。

### 配套组件选择

| 底模 | ControlNet 组件（hf 仓库） | 大小 | 说明 |
|---|---|---|---|
| SD1.5 | `lllyasviel/control_v11p_sd15_canny` 等（control_v11 全家桶） | ~1.4GB/个 | canny/depth/openpose 等按需下载 |
| SDXL | `diffusers/controlnet-canny-sdxl-1.0`（官方 Canny） | ~2.5GB | 另有 depth/softedge 等社区版 |

### 实现要点（diffusers 0.39 已支持）

```python
from diffusers import StableDiffusionXLControlNetPipeline, ControlNetModel

controlnet = ControlNetModel.from_pretrained(
    "diffusers/controlnet-canny-sdxl-1.0", torch_dtype=torch.float16
)
# 单文件 XL 底模 + ControlNet 组合（moyu_xl / realvisxl 用这条）
pipe = StableDiffusionXLControlNetPipeline.from_single_file(
    ckpt_path, controlnet=controlnet, config=base_dir,
    torch_dtype=torch.float16, local_files_only=True,
)
# 或 diffusers 目录底模（sdxl_base）：
pipe = StableDiffusionXLControlNetPipeline.from_pretrained(
    base_dir, controlnet=controlnet, torch_dtype=torch.float16,
)
pipe(control_image=..., ...)
```

- SD1.5 同理：`StableDiffusionControlNetPipeline` + `lllyasviel/control_v11p_sd15_canny`。
- 需配套**预处理器**：canny 边缘检测可用 `opencv-python`（`cv2.Canny`）或 diffusers 的 `controlnet_aux`；pose 用 `controlnet_aux` 的 OpenPose。
- 显存：ControlNet 额外约 1GB 参数，本机 8GB + `enable_model_cpu_offload` 可跑。

## 第 3 层：IP-Adapter（人脸 / 风格 / 物体参考，需下载 ~2.6GB）

用途：参考图的**语义内容**（某人的脸、某件衣服、某风格）注入生成，不依赖结构。

### 配套组件选择

| 底模 | Adapter 文件 | image encoder | 大小合计 |
|---|---|---|---|
| SD1.5 | `h94/IP-Adapter/models/ip-adapter_sd15.safetensors` (~80MB) | `h94/IP-Adapter/models/image_encoder/` CLIP-ViT-H | ~2.6GB |
| SDXL | `h94/IP-Adapter/models/ip-adapter_sdxl.bin` (~75MB) | 同上（CLIP-ViT-H，SDXL 复用同一 encoder） | ~2.6GB |

### 实现要点（diffusers 0.39 内置 `load_ip_adapter`）

```python
pipe.load_ip_adapter(
    "h94/IP-Adapter", subfolder="sdxl/models", weight_name="ip-adapter_sdxl.bin",
    image_encoder_folder="models/image_encoder",  # 0.39 参数名以 API 为准
)
pipe.set_ip_adapter_scale(0.6)
pipe(image=ref_img, ip_adapter_image=ref_img, ...)
```

- 单文件加载的 XL 底模同样可用（`from_single_file` 后调 `load_ip_adapter`）。
- 8GB 显存：image encoder（~2.5GB）随 `enable_model_cpu_offload` 一起 offload，可跑。
- 注意：`load_ip_adapter` 在 0.39 已弃用部分旧写法，实施时以 diffusers 0.39 API 文档为准。

## 显存与性能评估（RTX 5060 Laptop 8GB）

| 模式 | 额外显存 | 备注 |
|---|---|---|
| 文生图（现状） | 0 | cpu offload 下正常运行 |
| 图生图 img2img | 0 | 共享组件，**已实现** |
| + ControlNet | ~1GB | offload 下可跑，生成稍慢 |
| + IP-Adapter | ~2.5GB（encoder） | offload 下可跑 |

## 推荐路线

1. ✅ 第 1 层 img2img —— 已完成，覆盖「构图/风格弱参考」大部分日常需求。
2. 第 2 层 ControlNet（Canny）—— 需要构图强约束时启用，下载 ~2.5GB。
3. 第 3 层 IP-Adapter —— 需要人脸/风格强参考时启用，下载 ~2.6GB。

各层可独立启用，互不依赖。
